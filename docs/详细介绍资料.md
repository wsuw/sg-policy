## 一、 总体概述与建设背景

### （一） 建设背景
随着国家能源转型战略的深入推进及新型电力系统建设的加速展开，电力规程、电价机制（如第四监管周期输配电价）、“十五五”电网数字化规划及各级供电营业规则日趋精细与复杂。在基层营销服务、供电营业窗口及规划决策等一线业务场景中，长期存在以下痛点：
1. **政策查阅繁琐**：政策规程分散在不同部门及多套系统中，传统检索依靠关键词死板匹配或人工翻阅，耗时费力且查全率低；
2. **合规诊断风险高**：大语言模型直接应用易产生事实幻觉，缺乏精准的条款溯源机制，难以满足电网安全合规的红线要求；
3. **响应延迟过长**：传统 ReAct 智能体多轮检索工具调用耗时达 45~70 秒，无法满足实时交互及窗口即时服务诉求；
4. **涉密安全与环境制约**：电力规章及规划预算包含大量敏感信息，必须满足电网局域网（Air-gapped）物理隔离环境下的私有化部署要求。

### （二） 指导思想与项目命名
本项目定名为 **“国网智策 Policy Copilot”（又名：国网电策通 / SG-Policy）**，秉承 **“字字有据，行行可溯，让电力决策触手可及”** 的建设方针，旨在打造国家电网基层一线首个 **“政策穿透落地、零转化本地渲染、全流向一站闭环”** 的智能决策沙盘与专家级助手。

## 二、 系统定位与北极星指标

### （一） 核心定位
系统依托 **“前店（Copilot 交互工作台）+ 后厂（高精度知识管理中台）”** 的敏捷协同架构，将大模型智能体技术与浏览器原生无损渲染技术深度融合，面向电力能源政策咨询、电网数智化规划预算穿透、供电方案合规诊断及营销规程落地提供全天候、高置信的决策支撑。

### （二） 北极星指标（NSM）及支撑指标体系

#### 1. 核心北极星指标：一次性高置信业务闭环率（First-Time High-Trust Business Closure Rate）
* **指标定义**：在供电营业窗口或基层客户经理服务场景中，无论初始诉求多么模糊或参数缺失，系统通过智能引导澄清、100% 依据现行规程进行无幻觉诊断，并通过原生物档渲染平滑定位至源文件具体条款行高亮展示，在单一会话流内直接生成合规答复公文或决策图表的成功闭环比例。
* **计算公式**：
  $$\text{一次性高置信业务闭环率} = \frac{\text{单一会话内“要素澄清} \rightarrow \text{100\% 行级溯源} \rightarrow \text{方案/公文生成”且零差错业务量}}{\text{系统接收总业务请求量}} \times 100\%$$

#### 2. 三大业务支撑指标
* **诉求要素澄清率（Clarification Rate）**：通过槽位填充与主动引导卡片，将初始模糊诉求成功补齐核心业务参数的比例达到 **95% 以上**；
* **行级高亮精准定位率（Line-Level Highlight Provenance Rate）**：点击答案引用角标后，源文件条款平滑定位与行级高亮成功率达 **100%**；
* **一站式业务闭环周期（Closure Cycle Time）**：从诉求输入、合规判定、条款核验到公文导出，端到端总耗时由传统 **30 分钟降至 1 分钟以内**。

### （二） 关键技术突破

#### 1. 前置双层意图门控与知识注入中间件（Pipeline RAG 架构）
针对传统 Agentic RAG 模式下多轮 ReAct 工具调用耗时长（45~70 秒）的瓶颈，系统创新实现了前置智能路由：
* **第一层（0ms 规则速判）**：通过高性能正则及电力领域专有特征词库，实现 90% 以上常见会话与高频业务词的零延迟分流；
* **第二层（~300ms 语义兜底）**：对模糊提问启用 1-Token 极速判别；
* **前置注入与单轮生成**：判定需查库后，在进入主 LLM 前并行完成 RAGFlow 检索并组装 `[REF:n]` 与 `[DOC:xxx]` 协议，实现首字延迟从 15 秒压缩至 **1 秒以内**，问答总耗时压缩至 **3~5 秒**，Token 成本降低 **60%**。

#### 2. `file-viewer` 浏览器端原生零转化渲染引擎
* **100% 局域网离线私有化适配**：无需依赖第三方云端或服务端重型 Office 转换集群，直接在客户端浏览器高效解析 Word、Excel、PDF 等全格式原件；
* **行级穿透定位与荧光笔高亮**：构建基于 `TreeWalker` 的深度 DOM 文本匹配算法，用户点击消息中 `[Fig. n]` 切片角标即可平滑滚动至源文件精准条款行，以荧光笔效果即时高亮。

#### 3. 隔离式 `AgentState` 多轮会话状态管理
后端将检索到的切片数据与文档聚合清单按照每次会话的消息 ID 进行严格隔离，封装入 `AgentState.rag_citations` 中，彻底解决了多轮连续提问中上下文引用串扰、历史切片丢失等难题。

#### 4. A2UI 动态生成式智能画板
结合 Agent 结构化输出协议，支持根据政策内容或业务需求即时动态渲染出交互式电价图表、电网“十五五”数字化项目投资预算表与政策全景雷达图。

## 五、 部署运行与安全保障规范

### （一） 运行环境与前置要求
* **基础环境**：Node.js 18+ (推荐 Node 20+)、Python 3.10~3.12、`uv` 包管理器；
* **知识库底座**：企业级 RAGFlow 容器化集群实例，挂载相关政策制度 Dataset；
* **大模型服务**：支持标准 OpenAI 接口规范的私有化部署大模型（如通义千问 Qwen、DeepSeek 等）。

### （二） 安全与隐私保障机制
1. **网络边界物理隔离（Air-Gapped Ready）**：所有前端静态资源、Agent 逻辑与知识库均支持离线部署于国网内网，杜绝数据出境风险；
2. **零数据留存渲染**：文件预览均在本地内存中解析渲染，不向第三方任何公网 API 发送任何文件流或涉密元数据；
3. **内容防伪与合规审计**：全流程所有诊断结论均强制绑定 `[REF:n]` 溯源索引，确保输出内容“字字有据、事后可查、审计无忧”。
